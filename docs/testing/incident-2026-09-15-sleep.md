## 결론과 범위

수면 복귀 때 일시적인 모니터 연결 변화를 영구적인 그리기 대상 변경으로 처리하는 문제와, 1x에서 생성된 창을 2x 화면으로 배치할 때 기존 창 배율로 물리 좌표를 환산하는 문제를 실제 로그에서 확인했다. 포커스 불일치도 함께 관찰했다. 사용자가 어느 화면에 획을 시도했는지는 로그에 없으므로 각각의 기여도를 단정하지 않는다. 이전 Canvas context 복원 시 재그리기 누락과는 다른 경로다.

준현님은 이후 화면 선택 없이 모든 연결 화면에 그리도록 요청했다. 후속 구현은 선택 상태 자체를 제거하고 모든 연결 창에 입력을 열며, macOS 배치·활성화 순서도 함께 수정한다. 장시간 수면 복귀가 해결됐다는 판정에는 후속 실제 수면·연결 검사가 필요하다.
