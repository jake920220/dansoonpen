# Windows v0.7.1 설치·실기 테스트

이 문서는 설치 파일을 받은 사용자가 확인할 항목이다. 자동 빌드·설치 검사와 실제 PC의 화면 입력 검사를 구분한다.

## 설치

- Windows 10/11 **x64(일반 Intel/AMD PC)**용이다. Windows ARM 네이티브 빌드는 제공하지 않는다.
- [v0.7.1 릴리스](https://github.com/jake920220/dansoonpen/releases/tag/v0.7.1)에서 `DansoonPen-0.7.1-Windows-x64-setup.exe`를 받는다.
- 기존 앱이 실행 중이면 종료하고 설치한다. Node.js·Rust·개발 도구는 필요하지 않다.
- WebView2가 없으면 설치 과정에서 다운로드하므로 인터넷 연결이 필요할 수 있다.
- 코드 서명 인증서가 없는 테스트 배포본이다. Windows가 알 수 없는 게시자/SmartScreen 안내를 표시할 수 있다. 저장소와 체크섬을 확인하고, 조직 정책이 차단하면 관리자에게 확인한다. 보안 기능을 전역으로 끄지 않는다.

## 우선 확인할 7가지

| 항목 | 직접 해 볼 동작 | 기대 결과 |
| --- | --- | --- |
| 설치·첫 실행 | 설치 후 시작 메뉴에서 DansoonPen 실행 | 설정 화면이 열리고 오류 없이 준비 상태 |
| 그리기 전환 | 다른 앱 위에서 `Alt+Shift+Z` → 선 그리기 → 다시 `Alt+Shift+Z` | 펜·메뉴 독이 나타나고, 해제 시 필기는 남으며 뒤 앱을 클릭·스크롤 가능 |
| 전체 지우기 | 텍스트 또는 형광펜 선택 후 `Alt+Shift+X` | 필기만 사라지고 선택 도구와 메뉴 독 유지 |
| 기본 펜 복귀 | 텍스트 도구 상태에서 모드 해제 후 다시 진입 | 기본 펜 선택 |
| 한글 재편집 | T → 한글 직접 입력 → Enter → 기존 글 클릭 → 수정 | 한글 조합·받침·마지막 글자 정상, 기존 글 수정 가능 |
| 설정·언어 | `Ctrl+,` → 언어·색·크기·단축키 변경 → 종료·재실행 | 저장값 유지, 변경한 단축키로 작동 |
| 모니터·화면공유 | 모니터별로 선·텍스트 작성, 도구막대 이동, 전체 화면 공유 | 마우스와 필기 좌표 일치, 수신 화면에도 필기 표시 |

모니터가 여러 대라면 100%/125%/150% 등 배율을 함께 적는다. 가능하면 10분 이상 사용하며 앱 전환·모드 전환을 반복한다. 회색/검은 오버레이나 단축키 무반응이 생기면 발생 시각, 앞에 있던 앱, 직전 동작을 기록한다.

필기는 앱을 종료하면 사라진다. 설치 검사 통과만으로 위 동작이 검증된 것은 아니다.

## 결과 공유 양식

```text
Windows 버전:
CPU 종류(x64 Intel/AMD 등):
모니터 수와 각 배율:
설치 / 첫 실행: 정상 또는 증상
모드 전환 / 전체 삭제: 정상 또는 증상
한글 입력 / 기존 텍스트 수정: 정상 또는 증상
언어 / 설정 유지: 정상 또는 증상
화면공유 앱과 수신 화면:
오류 시각 / 재현 순서:
```

진단 로그가 필요하면 [로그 안내](diagnostics.md)를 참고한다. 로그·스크린샷을 공유하기 전에 개인정보와 강의 자료를 확인한다.
