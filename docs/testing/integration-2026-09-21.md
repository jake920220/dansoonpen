# v0.7.0 통합·공개 준비 검증

2026-09-21. 기존 main의 한국어·영어 기능에 별도 `codex/all-displays-drawing` 작업본(v0.6.3)의 변경을 통합했다. 기존 작업 폴더는 변경하지 않았으며 복사 전후 SHA-256으로 내용 보존을 확인했다. 양쪽 파일·기준 파일·기존 앱·설정은 Git에서 제외되는 로컬 artifacts에 백업했다.

## 통합 내용

- 모든 연결 화면의 그리기 입력, 화면 간 공유 도구막대, 화면별 커서 강조.
- macOS 혼합 배율 창 배치와 입력·포커스 복구, 텍스트 드래그 중 브라우저 선택 방지.
- 새 화면 안내·도구막대·트레이 항목의 영어 번역. 설정 언어와 저장된 도구막대 위치를 함께 보존한다.
- 기본 펜 설정 복원에서 언어와 도구막대 필드를 제외한다. 도구막대 필드는 별도 네이티브 명령에서 관리하므로 일반 설정 patch로 보내면 거부되는 통합 충돌을 해결했다.
- 버전은 기존 실행 앱보다 높은 v0.7.0으로 통일한다.

## 자동 검증

- 프런트엔드: 13개 파일, 59개 테스트 통과.
- Rust: 54개 테스트 통과. 언어 마이그레이션 시 사용자 도구막대 위치·접힘 보존 검증을 보강했다.
- Svelte 오류·경고 0, Rust fmt 및 Clippy 경고 금지 통과.
- 잠금 파일 의존성 버전은 유지했다. 고지 생성·일치 검사 통과(20 npm / 283 Cargo).
- macOS arm64 release 번들 빌드와 설치 복사본의 ad-hoc strict 서명 검사 통과.

## 실제 macOS 관찰

통합 앱 v0.7.0을 기존 실행 위치에 적용했다. 한국어 시작 화면에서 연결된 화면 2개 표시, 설정에서 English 선택, 영문 설정창·그리기 도구막대·macOS Settings 메뉴를 확인했다. 기본 노란색 14px, 글자 40px, 지우개 48px, 사용자 프리셋·단축키는 보존됐다.

디스크 설정의 변경 필드는 `version`과 `language`뿐이었다. `language: en` 저장을 확인했다. 해당 검사 세션에서 실패한 네이티브 명령은 없었다. 이는 모든 OS 조합이나 장시간 안정성을 보증하는 결과가 아니다.

그리기 중 수동 입력이 함께 감지되어 자동 마우스 조작을 중단했다. 최초 확인한 빈 장면 이후 생긴 필기와 모드 전환을 자동 테스트 결과로 귀속하지 않았다. 따라서 이번 세션에서 물리 전역 단축키·삭제 도구 유지·양쪽 화면의 실제 획을 독립적으로 재검증했다고 기록하지 않는다. 현재 코드의 회귀 테스트와 이전 [도구막대 이동 검사](toolbar-2026-09-15.md)를 구분해 참고한다.

Windows, 화면공유 수신 기기, 장시간 수면 복귀는 이번 검증에 포함하지 않았다.
