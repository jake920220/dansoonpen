# 강의 사용성 개선 — 2026-09-09

준현님 요청: 높은 우선순위 3개, 중간 우선순위 2개를 단계별 구현하고 부작용을 검증한다. 그리기 재진입은 저장된 기본 펜으로 시작한다.

## 진행 순서

1. 기본 펜 재진입: 실제 모드 진입에서만 초기화. 늦은 도구 변경 응답이 기본값을 덮지 않도록 검증.
2. 지우개 크기 분리: 펜/형광펜 굵기와 독립, 기존 설정 및 프리셋 호환.
3. 빠른 크기 조절: 도구별 작은/중간/큰 값과 미리보기, 텍스트의 `[ ]` 처리.
4. 기존 텍스트 이동·크기·색 수정: 취소/IME/undo/clear barrier와 화면 경계 보존.
5. 간단 도구막대: 더보기로 확장 도구 접근, 기존 이동/접기/위치 복원 보존.
6. 모드 전환·삭제 결과 안내: 완료된 상태 기반 안내, 삭제 되돌리기, 앱 조작 중 입력 통과 보존.

## 공통 검증 기준

- 각 단계에서 관련 회귀 테스트와 Svelte 검사, 네이티브 변경 시 Rust 테스트를 실행한다.
- 최종 전체 테스트, fmt/clippy, 고지 일치, production 및 macOS 빌드를 확인한다.
- UI 흐름과 네이티브 입력/포커스/투명도 검증을 구분한다. Windows 및 공유 수신 미검증은 그대로 표시한다.
- 시간 경과/모드 전환으로 필기를 지우지 않는다. 삭제 후 새 필기는 보존한다.
- 기존 색·굵기·프리셋·사용자 필기를 검증 편의를 위해 임의로 덮어쓰지 않는다.

## 기반 안정성 수정

별도 `codex/stability-audit-20260908`의 Canvas 복원 수정, 회귀 테스트 및 보고서를 반영했다. 기존 단축키/회색 화면 사건의 원인 확정을 의미하지 않는다.

## 단계별 결과

### 1. 기본 펜 재진입

- 성공한 interact→draw 전환에서 저장된 기본 펜·색·굵기 복원. draw→draw 화면 선택은 유지.
- brushGeneration으로 이전 진입의 지연 도구 변경을 거부하고 프런트 대기 변경/낙관적 값을 해제한다.
- 프런트 46개, Rust 41개 통과, Svelte 오류/경고 0. 지연 응답·대기 요청 취소·새 요청 보존 및 사용자 기본값 보존을 검사했다.
- 실제 macOS 전역 키/포커스 검증은 최종 빌드 후 별도 확인한다.

### 2. 지우개 크기 분리

- 지름 48px 기본값, 16–128px 독립 조절. 펜 굵기와 형광펜 굵기에 영향을 주지 않는다.
- 설정 v5로 이전하고 과거 프리셋에 지우개 필드를 보충한다. 기존 사용자 값은 보존한다.
- 프런트 46개, Rust 42개, Svelte 오류/경고 0. v4 파일/프리셋 로딩·사용자 값 왕복·잘못된 크기 거부·도구 간 독립성 검사 통과.

### 3. 빠른 크기 조절

- 도구별 작은/보통/큰 값, 슬라이더, 실제 CSS 크기 미리보기 및 현재 px 표시. `[ ]`는 글자 크기·지우개 지름·형광펜 굵기 각각 조절한다.
- 프런트 48개 및 Svelte 오류/경고 0. 도구별 필드 독립성·상하한·비정상 수치 거부 검사.
- CUA 브라우저 UI에서 텍스트 40→크게 64→`]` 66px 및 미리보기 확인. Esc로 앱 조작 후 재진입 시 기본 펜 선택 확인. 네이티브 전역 키 판정 아님.

### 4. 텍스트 이동·서식

- 기존 글 클릭 후 손잡이 드래그/방향키 이동, 빠른 색상·크기 변경. 편집 중 패널도 해당 글의 서식을 표시한다.
- 내용이 같아도 위치/색/크기만 바뀌면 동일 ID 교체로 저장하며 한 번의 undo로 복구한다. 취소는 원문을 유지한다.
- 프런트 50개, Rust 43개, Svelte 오류/경고 0. 서식만 변경·경계 제한·원문 보존·한 번의 undo/redo·삭제 세대 검사를 포함한다.
- CUA 브라우저: 2줄 한글 작성→기존 글 클릭→민트 64px→키보드 10px 이동 및 드래그→완료→재선택 시 위치/서식 유지. 수정 취소 후 undo 한 번으로 원래 210,330 위치/노란 40px 복구. 입력 중 `[` 문자 보존 확인. 실제 IME 조합 검증과는 구분한다.

### 5. 간단 도구막대

- 자주 쓰는 도구를 기본 표시하고 더보기로 전체 도구를 펼친다. 단축키로 선택한 형광펜/화살표와 켜진 커서 강조는 간단 보기에서도 접근 가능하다.
- 화면별 위치·접힘·더보기 선택을 독립 저장하며 과거 위치 데이터는 그대로 읽는다.
- 프런트 51개, Svelte 오류/경고 0. CUA 브라우저에서 더보기→접기→새로고침→펼치기 시 전체 도구 복원, 간단 보기에서 H로 형광펜 선택/버튼 표시를 확인했다.
