# 강의 사용성 개선 — 2026-09-09

준현님 요청: 높은 우선순위 3개, 중간 우선순위 2개를 단계별 구현하고 부작용을 검증한다. 그리기 재진입은 저장된 기본 펜으로 시작한다.

## 진행 순서

1. 기본 펜 재진입: 실제 모드 진입에서만 초기화. 늦은 도구 변경 응답이 기본값을 덮지 않도록 검증.
2. 지우개 크기 분리: 펜/형광펜 굵기와 독립, 기존 설정 및 프리셋 호환.
3. 빠른 크기 조절: 도구별 작은/중간/큰 값과 미리보기, 텍스트의 `[ ]` 처리.
4. 기존 텍스트 이동·크기·색 수정: 취소/IME/undo/clear barrier와 화면 경계 보존.
5. 간단 도구막대: 더보기로 확장 도구 접근, 기존 이동/접기/위치 복원 보존.
6. 모드 전환·삭제 결과 안내: 완료된 상태 기반 안내, 삭제 되돌리기, 앱 조작 중 입력 통과 보존.

## 공통 검증 기준

- 각 단계에서 관련 회귀 테스트와 Svelte 검사, 네이티브 변경 시 Rust 테스트를 실행한다.
- 최종 전체 테스트, fmt/clippy, 고지 일치, production 및 macOS 빌드를 확인한다.
- UI 흐름과 네이티브 입력/포커스/투명도 검증을 구분한다. Windows 및 공유 수신 미검증은 그대로 표시한다.
- 시간 경과/모드 전환으로 필기를 지우지 않는다. 삭제 후 새 필기는 보존한다.
- 기존 색·굵기·프리셋·사용자 필기를 검증 편의를 위해 임의로 덮어쓰지 않는다.
